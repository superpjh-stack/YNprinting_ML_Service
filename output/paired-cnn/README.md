# 정합 및 대응 영역 CNN 개선 실험

## 적용한 변경

기존 16×16 복원 모델 대신 원본 300dpi 시안에서 64×64 영역을 잘라 대응 쌍을 입력하는 CNN을 학습했다. 기준 이미지, 정합된 비교 이미지, 절대 차이의 3채널을 사용한다. 3×3 stride-2 합성곱 6채널, ReLU, 전역 평균/최대 풀링, sigmoid 분류기를 사용하며 모든 가중치를 합성 정상/불량 쌍의 BCE와 Adam으로 학습했다. 엄밀한 공유 인코더 Siamese 구조가 아니라 두 이미지를 함께 입력하는 비교 CNN이다.

정합은 위상 상관 기반 정수 이동만 지원한다. 회전·원근·확대축소 정합은 아직 없다. 상관계수 0.75 및 겹침 75% 기준에 못 미치면 판정 가능 자료로 사용하지 않는다. 겹치지 않는 경계는 비교에서 제거한다.

## 학습 및 시험

시안 그룹 분할은 학습 31장/보정 11장/시험 11장이다. 각 시안의 고대비 영역 4개에서 정상·지움·검은점·흐림 쌍을 생성했다. 전체 자료는 실제 사진이 아닌 합성 쌍이다. 고정된 작은 위치·밝기 변동을 추가했으며 모든 파생 쌍은 원본의 분할을 유지했다.

학습 458쌍, 보정 154쌍, 시험 162쌍. 총 제외 74쌍 중 정합 탈락 37쌍, 변형이 실질적으로 발생하지 않은 사례 37쌍이다. 제외 후 지표만으로 전체 수집 흐름 성능을 주장하지 않는다.

30 epoch 학습. 보정 BCE로 epoch를 선택하고 보정 정상 경보율 5% 이하 조건에서 합성 F1 최대 임계값을 선택했다. 동률이면 높은 임계값을 선택한다. 시험 결과로 임계값을 재조정하지 않았다.

| 지표 | 정합 통과 합성 ROI 시험 |
|---|---:|
| 표본 | 162쌍 (정상 44 / 합성 불량 118) |
| Accuracy | 81.48% |
| Precision | 96.81% |
| Recall | 77.12% |
| F1 | 0.8585 |
| AUROC | 0.9728 |
| 정상 경보율 | 6.82% (3/44) |

혼동행렬은 실제 OK/NG 행, 예측 OK/NG 열 기준 [[41,3],[27,91]]이다. 정상 경보율이 보정 제한 5%를 시험에서는 초과했다.

## 실제 사진 정합 점검

267장 중 단일 시안 후보 부재 37장, 종횡비 불일치 101장, 단순 이동 정합 실패 114장, 정합 기준 통과 15장이다. 크기 비율이 유사한 경우만 축소된 전체 시안과 사진을 비교한 사전 점검이다. 정합 통과 15장도 사진 속 표시 및 시안 개정판 검수가 없으므로 학습·성능시험에 사용하지 않았다. 이 수치는 실제 불량 검출 성능이 아니다.

## 제한과 다음 단계

**실험 모델이며 운영 추천은 보류한다.** 이전 시험은 이미지 단위 정상 기반 이상탐지였고 이번은 합성 정상/불량 지도학습 및 ROI 단위다. F1 상승을 같은 조건의 개선으로 해석하면 안 된다. 같은 시안에서 나온 ROI는 서로 독립적이지 않고 시험 시안도 이미 관찰한 탐색 자료다. 고대비 상위 4영역 외 결함은 평가하지 않았다. 실제 사진에서 참조 개정판·표시 없는 원본을 검수하고 회전·원근·관심영역 매칭을 추가해야 한다. 신규 현장 독립 평가 없이 최종 목표 달성을 선언하지 않는다.

## 파일

- model.joblib / weights.npz: 모델 및 학습 가중치. 신뢰한 로컬 파일만 로드.
- report.json: 학습 곡선·임계값·시험 지표.
- dataset.json: 원본 해시·분할·ROI 위치·합성 유형·정합 결과·시험 점수.
- photo-alignment-audit.json: 실제 사진별 사전 점검 결과.

재실행: `.venv/bin/python -m api.paired_experiment`.
