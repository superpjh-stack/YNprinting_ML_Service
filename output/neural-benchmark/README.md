# CNN·RNN·MLP 적용 및 학습 결과

정상 PDF 시안 53장 중 학습 31장, 보정/조기종료 11장, 탐색 시험 11장을 사용했다. 정상 학습 패치는 496개다. 실제 불량은 학습하지 않았다. 세 모델 모두 80 epoch를 수행했다.

## 구현

PyTorch 다운로드가 DNS 실패로 불가능하여 NumPy로 역전파와 Adam을 구현했다. 고정 랜덤 필터나 이름만 신경망인 모델이 아니라 모든 가중치를 MSE 손실로 최적화했다. 각 파라미터 텐서의 수치 미분 검증 및 학습·저장·재로딩 테스트를 수행했다.

- CNN-AE: 16×16 회색조 패치 → 3×3 stride 2 합성곱(4채널) → ReLU → 196개 특징 → tanh 16차원 잠재공간 → 256픽셀 sigmoid 복원.
- RNN-AE: 패치의 16개 행을 순서대로 읽는 tanh RNN(은닉 16) → 마지막 은닉 상태 → 256픽셀 복원. LSTM/GRU가 아닌 기본 RNN이며 생산 시계열 모델이 아니다.
- MLP-AE: 256픽셀 → tanh 16차원 → 256픽셀 sigmoid 복원.

## 결론

**운영 추천 모델 없음.** 복원을 잘하는 것과 결함을 구별하는 것은 다르다. 16×16 축소는 작은 문자 결함을 소실시킬 수 있고 여러 디자인의 정상 구조 차이가 결함보다 클 수 있다. CNN-AE라는 후보 이름은 보정 세트 합성 F1 및 이름순 동률 규칙의 출력일 뿐 우수성을 입증한 결과가 아니다.

시험 결과를 보고 임계값을 낮춰 성능을 다시 계산하지 않았다. 다음 개선은 원본 시안과 사진의 정합, 더 높은 해상도의 문자/결함 관심영역, 실제 검수 라벨을 활용한 Siamese CNN 또는 검출 모델 비교다. 동일 시험 자료는 이미 관찰했으므로 최종 현장 평가는 신규 데이터로 해야 한다.

## 산출물

- 각 이름의 `.joblib`: 모델·임계값·전처리 버전. 신뢰한 로컬 파일만 로드한다.
- `*-weights.npz`: 신경망 가중치.
- `report.json`: epoch별 손실, 모델별 지표·임계값·점수.
- `dataset.json`: 원본 해시 및 그룹 분할.

실행: `.venv/bin/python -m api.neural_benchmark`. 기존 모델을 덮어쓰지 않고 화면 성능측정 탭에 신경망 비교를 별도로 추가했다. 실제 불량·OCR·칼날 성능은 아직 검증되지 않았다.
