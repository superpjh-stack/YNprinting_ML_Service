# 정상 시안 기반 5개 모델 학습·평가

53개 정상 참조 시안을 그룹별 학습 31장, 임계값 보정/후보선정 11장, 탐색 시험 11장으로 나눴다. 각 모델은 동일한 20차원 격자 특징과 train 전용 StandardScaler를 사용했다. LOF는 신규 데이터 평가를 위한 novelty=True를 적용했다.

합성 시험은 정상 시험 11장으로부터 영역 지움·검은 얼룩·가우시안 흐림을 각 1장씩 만든 33장이다. 실제 불량 정답이 아니며 문자 오탈자나 칼날 결함을 대표하지 않는다. 합성 변형은 학습에 사용하지 않았다.

| 모델 | 정상 경보 수/11 | 경보율 | 합성 Recall | 합성 F1 | 합성 AUROC | 추론 p95 ms |
|---|---:|---:|---:|---:|---:|---:|
| IsolationForest | 1/11 | 9.1% | 15.2% | 0.256 | 0.555 | 3.416 |
| OneClassSVM | 4/11 | 36.4% | 42.4% | 0.549 | 0.503 | 0.082 |
| LOF | 2/11 | 18.2% | 18.2% | 0.293 | 0.552 | 0.967 |
| kNN | 5/11 | 45.5% | 48.5% | 0.593 | 0.558 | 0.926 |
| PCA | 3/11 | 27.3% | 27.3% | 0.400 | 0.555 | 0.057 |

## 해석 및 추천

검증 합성 F1을 기준으로 미리 정한 후보는 **PCA**다. 시험 F1이 가장 높은 모델을 보고 후보를 바꾸지 않았다. 현재는 **운영 추천 모델 없음**으로 결론낸다. kNN은 시험 합성 F1이 상대적으로 높지만 정상 11장 중 5장에 경보를 내므로 실용적이지 않다. Isolation Forest는 경보가 적지만 합성 결함 대부분을 놓친다.

다섯 후보를 선택한 이유: Isolation Forest는 무작위 분리, One-Class SVM은 정상 경계, LOF는 지역 밀도, kNN은 정상 표본까지의 거리, PCA는 특징 복원오차로 이상을 판단해 서로 다른 가정을 비교할 수 있다. 이는 비교 실험 후보 추천이지 운영 적합성 보증이 아니다.

## 평가의 한계

- 기존 시험 11장은 앞선 실험에서 이미 관찰했다. 이번 결과는 새로운 독립 검증이 아닌 탐색 비교다.
- 정상 11장 중 한 장의 차이가 경보율 9.09%p다. 점추정 순위에 과도한 의미를 두지 않는다.
- 합성 혼합 비율은 정상 25%/변형 75%이므로 Precision·F1을 현장 불량률에 적용할 수 없다.
- 여러 합성 사진이 같은 시안에서 파생되어 독립 표본이 아니다.
- 4×4 영역의 통계 특징은 작은 문자 변화와 제품별 정상 구조를 충분히 설명하지 못한다.
- 모든 모델의 AUROC가 약 0.5~0.56으로 분리력이 약하다.
- 모델 추론 시간은 피처 추출과 파일 읽기를 제외한 로컬 CPU 반복 측정값이다.

피처 추출 및 읽기: p50 12.28 ms, p95 46.97 ms.

## 다음 개선 방향

시안과 사진의 기하 정합·촬영 조건 보정 후, 대응 영역 차이와 OCR 문자 비교를 결합해야 한다. 표시 없는 정상/불량 실촬영본으로 새로운 독립 시험 세트를 확보한다. 정상 시안만으로 정상 촬영 분포를 대신할 수 없으며 목형 모델은 별도 자료가 필요하다.

## 재현 및 저장

`api/model_benchmark.py`를 `python -m api.model_benchmark`로 실행한다. 모델 5개는 각 이름의 joblib, 전체 지표·혼동행렬·점수는 report.json, 원본 해시·분할은 dataset.json에 저장했다. 이 저장 모델은 실험용이며 운영 모델 목록을 변경하지 않았다.

기술 근거: [scikit-learn 이상탐지](https://scikit-learn.org/stable/modules/outlier_detection.html), [PCA 복원](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html).
