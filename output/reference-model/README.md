# 정상 시안 이상탐지 학습 결과

사용자가 지정한 PDF 정상 시안 53장을 기준으로 IsolationForest 실험 모델을 학습했다. 4×4 격자별 밝기·대비·에지·히스토그램 특징을 사용하며 정상 시안의 시각적 분포에서 벗어난 정도를 계산한다. 시안별 정합이나 OCR 비교는 하지 않는다.

- 그룹별 학습 31장, 임계값 보정 11장, 시험 11장
- 학습 영역 496개, 트리 300개, 시드 42
- 임계값은 보정 세트 이미지 점수의 95백분위수(상위 관측값)로 고정
- 시험 정상 시안 11장 중 1장 경보, 참조 시안 경보율 9.09%
- 이 경보율은 정상 시안에서의 결과이며 불량 탐지 정확도나 Recall이 아니다.

`model.joblib`은 모델과 임계값·전처리 버전, `dataset.json`은 이미지별 분할·점수와 원본 해시, `report.json`은 지표 및 제한사항이다. 신뢰한 로컬 모델 파일만 joblib으로 읽는다.

기존 불량 사진 232장은 동일 PDF가 있는 연결 후보지만 정합·표시 제거·사진별 정답 검수를 마치지 않아 학습이나 평가에 투입하지 않았다. 정상 PDF와 불량 사진을 단순 이진분류해 촬영 도메인 차이를 학습하는 방식을 피했다.

목형 칼날 정상 데이터가 아니므로 칼날 모델은 학습하지 않았다. 실제 정상/불량 촬영본으로 별도 검증하기 전 운영 배포하지 않는다. PDF 자체의 재단선·분판·치수 및 다양한 디자인이 이상 점수에 영향을 줄 수 있다. 새 디자인에 대한 경보가 실제 결함을 의미하지 않는다.

재실행:

```sh
.venv/bin/python -m api.reference_training
```

현장 실촬영 기준모델과 별도의 실험이며 기존 정답 검수 상태를 변경하지 않았다. 성능측정 화면에서 이 실험 결과를 별도로 조회할 수 있다.
