# 와이엔프린팅 검사 애플리케이션 — 로컬 파일럿

## 제공 흐름

앱의 첫 화면인 `검사·이력`에서 기준 시안과 CNN 모델을 선택하고 검사 사진을 등록한다. 기준과 사진에서 같은 내용의 64×64 영역을 지정한 후 검사자·LOT를 입력하고 실행한다. 화면 클릭 또는 숫자 좌표 입력을 지원한다. 모델 점수는 보정된 불량 확률이 아니다.

정합 성공 시 지정한 영역의 정상/이상 후보를 표시하고 실패 시 판정 불가를 표시한다. 선택하지 않은 영역의 정상 여부는 검사하지 않는다. 작업자는 사진을 확인한 뒤 선택 영역 정상·불량·재검을 저장한다. 검사 이력에서 기존 결과와 작업자 판정 변경 기록을 조회할 수 있다. 이는 출하 승인 시스템이 아니다.

## 기능 및 설계 대응

| 설계 항목 | 이번 구현 |
|---|---|
| 이미지 등록 | PNG/JPG 업로드·원본 해시 보존·EXIF 표시 방향 일치 |
| 기준 선택 | PDF에서 추출한 53개 시안 후보 목록 및 미리보기 |
| 모델 적용 | 학습 완료한 CNN 6개 설정 선택; kernel5 기본값 |
| 검사 실행 | 수동 대응 영역 선택, 이동 정합, CNN 점수 |
| 실패 처리 | 정합 실패 판정 불가 및 이력 저장, 미학습 목형 차단 |
| 결과 근거 | 입력 좌표·모델/이미지 해시·임계값·점수·검사자·LOT |
| 이력 | SQLite 영속 저장, 제한된 페이지 조회, 요청 멱등성 |
| 최종 검수 | 작업자 선택 영역 판정, 수정 대신 판정 추가 이력 |
| 학습 준비 | 기존 데이터 수집·정제·피처·라벨링·학습·평가 화면 유지 |

## 실행

```sh
./scripts/start-local.sh
```

http://127.0.0.1:8042 에 접속한다. 포트를 바꾸려면 `YN_PORT=8043 ./scripts/start-local.sh`를 사용한다. 현재 배포 범위는 사용자 PC의 loopback 단일 사용자 파일럿이다. 원본과 검사 이력은 `.runtime/`에 저장되며 삭제하면 복구되지 않으므로 서버 종료 후 폴더를 백업한다. 시안과 모델은 `output/reference-images`, `output/cnn-hyperparameters`를 함께 보존한다. 입력 사진이나 시안을 외부 서비스에 보내지 않는다.

## 운영 전 필요한 단계

이 애플리케이션은 검증된 상용 검사 서비스가 아니라 기능 검증용 로컬 파일럿이다. 인증·역할별 권한, HTTPS 공유 접속, 서버 배포, 백업 복구 자동화, MES 연동, 카메라 연결은 아직 구현/설정하지 않았다. 공개 IP로 직접 실행하지 않는다. 공유 서버 운영으로 전환하려면 위 항목과 실제 정상/불량 독립 평가를 완료해야 한다.

OCR 자동 문안 판독, 회전/원근/배율 정합, 자동 전체 이미지 ROI 탐색은 미구현이다. 사진의 64픽셀 영역과 시안의 64픽셀 영역이 같은 내용을 같은 배율로 나타내야 한다. 사진에 박스나 필기가 있으면 입력 확인을 통과시켜서는 안 된다. 기존 데이터에서 표시 있음으로 검수된 사진은 API에서 차단한다. 사용자 확인은 모델 품질 검증이나 관리자 승인으로 간주하지 않는다.

목형 모델은 데이터 부족으로 미학습이며 목형 화면에는 준비 상태를 제공한다. 문안 모델을 목형 검사에 재사용하지 않는다.
