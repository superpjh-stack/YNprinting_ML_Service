# 와이엔프린팅 현장 촬영·정답 검수 가이드

## 현재 자료 활용

기존 267장과 53개 PDF는 원본 그대로 보존한다. 불량 사례 조회, 유형 정리, 촬영 조건 비교, 원본 시안 대응 검토에 사용한다. 사진별 표시 유무와 촬영 대상을 확인하기 전 학습에는 편입하지 않는다. PDF는 참조 도안이며 정상 실촬영본이 아니다.

기존 자료는 목록의 불량 사유를 유지하되 문자 누락·오탈자, 인쇄 외관 결함, 기타 후공정 결함을 구분한다. 얼룩·기포·주름을 문자 오류로 재명명하지 않는다. 라벨의 타발불량을 칼날 파손 정답으로 사용하지 않는다.

## 1. 인쇄판 문안 검사 촬영

- 정상 인쇄판과 실제 이상 인쇄판을 같은 촬영대·카메라·조명·거리에서 촬영한다.
- 제품 코드, 시안 ID/개정판, 인쇄판 번호, LOT, 촬영 시각을 기록한다.
- 승인 시안 PDF와 해당 페이지, 문자 정답을 연결한다. 시안과 다른 개정판이면 불량으로 단정하지 않는다.
- 전체 사진과 작은 문자·기호를 읽을 수 있는 확대 사진을 함께 남긴다. 같은 대상의 사진·crop은 한 그룹에 둔다.
- 문자 누락, 오탈자, 번짐, 점/기호 결함 등을 실제 관찰한 경우에만 라벨링한다.
- 완제품 라벨 사진은 별도 도메인으로 관리한다. 인쇄판 학습의 정상 또는 불량으로 자동 편입하지 않는다.

## 2. 목형 칼날 검사 촬영

- 정상 목형과 실제 불량 목형의 전체 형상 및 칼날 확대 사진을 같은 조건으로 촬영한다.
- 목형 ID, 개정번호, 기준 형상, 작업지시·LOT, 촬영 시각을 기록한다.
- 휨, 끊김/파손, 마모, 위치 불량을 구분한다. 사진으로 확인할 수 없는 마모는 미확인으로 남긴다.
- 동일 목형의 여러 시점·확대 사진은 동일 그룹에 둔다. 제품 라벨의 절단 흔적만으로 칼날 불량을 확정하지 않는다.
- 위치 오차를 mm로 평가하려면 배율/캘리브레이션 근거를 함께 기록한다. 없으면 픽셀 단위만 사용한다.

## 3. 공통 촬영 규칙

1. 표시 없는 원본을 먼저 저장한다. 결함 위치를 설명하는 빨간 박스·원·화살표는 별도 라벨 파일 또는 표시용 복사본에만 작성한다.
2. 정상과 불량의 배경·조명·카메라가 한쪽으로 치우치지 않도록 한다.
3. 합성 결함, 지우개·인페인팅 보정본, PDF 렌더를 실제 정상/불량 촬영본으로 등록하지 않는다.
4. 흐림·반사·가림으로 판단이 어렵다면 다시 촬영한다. 파일을 덮어쓰지 않고 새 ID로 연결한다.
5. 불량을 만들기 위해 설비나 칼날을 손상시키지 않는다. 현장에서 확인된 사례를 수집한다.

## 4. 정답 검수 순서

담당자가 원본을 보고 촬영 대상 → 표시 유무 → 기준 시안 대응 → 정상/불량 및 결함 유형 → 그룹을 확인한다. 판단이 갈리면 품질 담당자가 재검한다. 미확인을 OK로 채우지 않는다. 검수자·시각·기준서 버전을 남긴다.

현재 화면에서 저장 가능한 항목은 서비스, 촬영 대상, 표시 유무, OK/NG, 검수자, 그룹, 촬영 도메인이다. 참조 개정판·좌표·문자 정답 등 세부 촬영 기록은 `collection-template.json`에 함께 보관한다. 이 JSON은 기록용이며 현재 자동 일괄 가져오기 기능은 없다.

## 5. 수집 순서와 종료 조건

먼저 두 서비스 각각 정상/불량을 포함한 소규모 촬영 묶음을 확보해 문자와 칼날이 실제로 판독되는지 확인한다. 촬영 조건을 고정한 후 제품군·목형·기간을 넓혀 수집한다. 정상과 실제 발생하는 각 불량 유형을 모두 포함하고 부족한 유형은 별도 기록한다.

개발 프로그램의 12장·6그룹 최소 조건은 실행 조건일 뿐 현장 성능을 입증하는 수량이 아니다. 그룹 분할 후 train/validation/test에 정상·불량이 모두 있어야 하며, 최종 표본수는 유형별 오류율과 신뢰구간을 검토해 결정한다. 새 품목과 후속 기간 자료는 독립 평가용으로 보존한다.

정상과 목형 자료가 확보되기 전 현재 자료만으로 두 서비스의 성능 달성을 선언하지 않는다.
