테스트는 실제 데이터와 분리된 임시 디렉터리에서 기준모델 학습, 저장, 평가까지 수행한다. 이 테스트 성능은 현장 지표가 아니다.

구현 범위·명령·미구현 항목은 README.md에 명시했다. 네트워크 DNS 오류로 로컬 패키지를 프로젝트 전용 환경에 복사했다. 포트 바인딩은 실행 환경에서 Operation not permitted로 거절되어 실브라우저 검증을 수행하지 못했다.

검증 결과: 백엔드 자동 테스트 8개 통과, TypeScript 검사 및 Vite production build 통과. TestClient로 정적 화면 응답과 모델 예측 API를 확인했다. 실제 브라우저 확인은 미수행이다.

## 수집 준비 후속 개발

촬영 대상 및 결함 표시 유무를 저장·감사 기록하고, 표시가 있거나 미확인인 이미지와 서비스 불일치 도메인을 학습·예측에서 제외했다. 267장 검수 대기 목록, 두 서비스 촬영 기록 JSON 양식, 현장 촬영 가이드를 작성했다. 최종 자동 테스트 14개와 프런트엔드 빌드가 통과했다. 실제 정답 검수·추가 촬영·학습은 아직 수행되지 않았다.

## 결함 위치 라벨링 후속 개발

사진 위 영역 드래그·좌표 입력, 서비스별 결함 유형, 기준/관찰 문구, 위치 검수 완료 상태, 변경 버전 및 감사 이력, 조건부 JSON 내보내기를 추가했다. EXIF 방향을 반영한 표시 이미지와 정규화 좌표를 사용하며 원본은 유지한다. 테스트 16개 및 production build 통과. 브라우저 실검증은 미수행이며 기존 포트 제한이 남아 있다. 실제 사진의 정답·결함 좌표를 자동 확정하거나 학습 성능을 생성하지 않았다.

## 검사 애플리케이션 연결

기준 시안 53개·CNN 6개 모델 조회, 사진 업로드, 64×64 대응 영역 지정, 이동 정합과 실제 CNN 추론, 판정 불가 처리, 검사 이력 및 작업자 최종 판정 추가를 구현했다. 검사 입력·모델·참조 해시를 보존하고 요청 키 중복/충돌을 처리한다. 테스트 40개, production build, 실제 kernel5 모델을 사용하는 격리 API smoke 검증 통과. 정상 시안 자체를 비교한 smoke 결과는 기능 검증이며 현장 성능이 아니다. 실브라우저 검증은 실행 환경 포트 바인딩 거절로 미수행했다. 공개 서비스·인증·MES·카메라 연동은 미완료이며 로컬 파일럿으로 제공한다.
