# 제공 폴더 대조 및 학습 적합성 검토

## 대조 결과

사용자가 지정한 `불량 제출 파일` 폴더를 재수집했다. 신규 0개, 동일 해시 267개, 오류 0개다. 기존 자료와 동일하므로 복제 적재하지 않았다.

목록은 데이터 61행(인덱스 21 누락), 사진 합계 267장, PDF 원본 합계 53개다. 모든 행에서 실제 파일 수와 목록 수가 일치한다. 사진이 있는 폴더는 60개다. 인덱스 61은 PDF 1개·사진 0개이며 자료 수집 누락으로 단정하지 않는다.

## 육안 확인

사진이 있는 폴더를 정렬해 5개 간격으로 대표 사진 12장을 축소 모음으로 확인했다. 여러 사진에 빨간 사각형, 원, 필기가 있으며 완제품 라벨 사진과 한 이미지 내 여러 라벨이 함께 보인다. 전체 267장의 표시 유무나 좌표를 검수한 것은 아니다.

원본 이미지에 결함 표시가 덧그려진 상태로 정상/불량을 학습하면 표시 자체가 정답을 알려주는 데이터 누수가 발생할 수 있다. 표시 없는 촬영 원본을 우선 확보한다. 표시를 지우거나 인페인팅한 이미지를 진짜 정상 데이터로 취급하지 않는다. 같은 이미지의 라벨 crop은 동일 그룹으로 묶는다.

## 서비스 적용 판단

인쇄판 문안 검사: 이 자료는 인쇄 라벨 외관 결함 사례와 참조 시안 후보로 활용 가능하다. 사진별 문안 오류 정답, 기준 시안 대응과 개정판, 표시 없는 실촬영본을 검수해야 한다. 목록상 얼룩·기포·주름·이물질 등을 문안 오탈자로 자동 변환하지 않는다.

목형 칼날 검사: 목록에 목형 촬영본으로 명시된 자료가 없다. 타발불량이 기재된 라벨 사례는 칼날 휨·마모·파손의 사진 정답으로 사용할 수 없다.

정상 데이터: 목록은 전부 불량사진으로 집계한다. PDF 원본은 참조 도안 후보이지 정상 실촬영 이미지가 아니다. PDF를 OK, 촬영 사진을 NG로 나누면 파일 매체의 차이를 배우므로 그렇게 학습하지 않는다.

## 산출물과 다음 입력

`folder-audit.json`: 61행 파일 수 대조 및 이미지 해시.
`label-review-manifest.csv`: 267장별 검수 대장. 서비스·표시 유무·표시 없는 원본·사진별 정답·검수자 확인란을 남겼다. 이 CSV는 검수용 산출물이며 현재 UI 자동 업로드 형식은 아니다.

이 자료만으로 두 서비스의 정상/불량 학습·독립 성능평가를 완료할 수 없다. 필요한 입력은 (1) 표시 없는 정상/불량 인쇄판 실촬영 사진과 기준 시안, (2) 정상/불량 목형 및 확대 사진과 기준 형상, (3) 이미지별 정답 및 검사 기준이다. 현재 검수 정답과 실제 학습 모델 수는 각각 0건으로 유지했다.
