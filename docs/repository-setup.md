# 저장소 설치와 로컬 데이터

저장소에는 애플리케이션 소스, 테스트, 설계/사용 문서, 실험 모델과 집계 보고서를 포함한다. 고객 원본 이미지·PDF 렌더, 개인 경로가 있는 데이터 manifest, 실행 DB, 의존성 폴더와 빌드 산출물은 제외한다.

새 체크아웃에서는 README 설치 명령과 프런트엔드 빌드를 실행한다. 모델의 joblib 파일은 이 저장소에서 신뢰한 버전만 사용한다. 실제 검사에 필요한 승인 시안은 별도로 제공받아 `output/reference-images/`에 준비해야 한다. 기존 로컬 작업공간의 해당 폴더에는 53장 참조 이미지와 manifest가 있다. 새 컴퓨터에서 학습을 재현하려면 제외된 원본 자료와 데이터 목록도 별도로 준비해야 한다.

이 저장소는 단일 사용자 로컬 파일럿이다. 실험 모델이 포함되어 있다는 사실이 운영 승인 또는 현장 품질 성능 보증을 의미하지 않는다.
